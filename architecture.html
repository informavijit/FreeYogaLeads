3. Technical Stack & State Specification

Lightweight, modern components ensuring zero-latency execution.

Frontend Core

  • HTML5 / Tailwind CSS: Dynamic utility-first layout with zero bundling overhead.
  • Vanilla JS (ES6+): Native event-driven reactive state pattern without React/Vue framework bloat.
  • Lucide Icons: Modern SVG iconography loaded asynchronously via unpkg CDN.

Storage & Persistence

  • localStorage: 100% private, browser-sandboxed database for CRM leads and API configurations.
  • Data Export: Native client-side Blob generator for UTF-8 encoded RFC-4180 CSV files.
  • Zero Server Storage: Eliminates GDPR/data protection compliance overhead.

AI & API Bridges

  • Google Gemini REST: Direct HTTP POST to v1beta/models/gemini-1.5-flash with structured JSON schema.
  • Overpass API: OpenStreetMap global spatial query engine.
  • Reddit JSON API: Public subreddit query engine with CORS proxy fallback.

Indian IVR & Telephony Engine

  • Dual-Path Calling: "Place Real Outbound IVR Call" (Cloud Gateway / PRI Trunk) & "Test Audio" (Browser TTS).
  • Web Audio Dual-Tone: Real DTMF dual-frequency sine generation (697–941Hz & 1209–1477Hz).
  • 7-Language Voice: Native SpeechSynthesis locales (Hindi, English, Telugu, Tamil, Kannada, Malayalam, Bengali).
  • Cloud Telephony Adapter: Exotel REST API, Twilio TwiML Voice XML, and Generic Webhooks (n8n/Zapier).

4. IVR Gateway & Lead Temperature Classification Engine

Architecture of the multi-lingual voice gateway, bulk campaign dispatcher, and return response qualification matrix.

Priority 1 🔥 Hot Leads

Qualification Conditions:

  • Pressed Key 1: Yoga Teacher Certification (YTTC 200/300hr).
  • Pressed Key 0: Live Call Transfer to Senior Yoga Counselor.
  • High-intent Reddit inquiry comparing certification costs.
➔ Auto-marked: Trial Booked (Value: ₹45,000)
Priority 2 ☀️ Warm Leads

Qualification Conditions:

  • Pressed Key 2: 1-on-1 Online Yoga Classes & Therapy.
  • Pressed Key 9: Instant WhatsApp Brochure & Curriculum Dispatch.
  • Pressed Key 3: Corporate Wellness & Gym Partnerships.
➔ Auto-marked: Contacted (Value: ₹5,000–₹25,000)
Priority 3 ❄️ Cold Leads

Qualification Conditions:

  • Call answered but prospect hung up before keypress.
  • Pressed unmapped or invalid DTMF digit.
  • Busy / Unanswered outbound dial attempts.
➔ Auto-marked: Contacted (Cold) (Queued for SMS/WA)

Dual-Path Call Execution Pipeline:

  • Path A: "Place Real Outbound IVR Call": Initiates outbound calling to target +91 mobile/landlines via Exotel REST API / PRI SIP Trunk or the local telephony_bridge.py on http://localhost:5000. Renders telecom handshake, delivers multi-lingual menu, logs call SID, and syncs response to CRM.
  • Path B: "Test Audio (Browser TTS)": Runs client-side audio rendering using Web SpeechSynthesis Utterances and Web Audio API DTMF oscillators for testing without consuming telecom credits.
  • Local Telephony Bridge: Zero-dependency Python server (telephony_bridge.py) running on port 5000 that bridges browser requests directly to Exotel, Twilio, and Indian PRI SIP trunks with CORS support.
  • 1-Click CRM/Directory Calling: Deep-links directly from lead cards with number auto-population and dialer focus.

Bulk 50+ Numbers Multi-Language Gateway (Keys 1 to 7):

When an outbound campaign to 50+ Indian phone numbers is launched, the IVR begins with the Multi-Language Audio Gateway: "For English press 1, हिंदी के लिए 2 दबाएं, తెలుగు కోసం 3 నొక్కండి, தமிழுக்கு 4, ಕನ್ನಡಕ್ಕಾಗಿ 5, മലയാളത്തിനായി 6, বাংলার জন্য 7" Upon DTMF capture of digit 1–7, the call branches into that language's qualification questions. Every prospect's responses are recorded in real-time and synchronized with the Lead CRM.

6. Deployment & Security Architecture

Zero infrastructure maintenance and strict client-side data isolation.

GitHub Pages Deployment

The application is completely static. When pushed to GitHub and configured with Pages from the main branch, GitHub serves the static assets over their global Fastly CDN with automated SSL certificates at zero monthly cost.

Client-Side Privacy Boundary & LocalStorage

Unlike third-party CRMs that store student phone numbers on remote servers, all phone numbers, scraped records, and Gemini API keys stay exclusively inside the user's browser localStorage. No telemetry or data leakage.

Critical Security Architecture: Why Keys Must Never Be Hardcoded

1. Client-Side Inspect (F12) GitHub Pages is a static server. Any key written in app.js is sent in plain text to the visitor's browser and can be read via Developer Tools (Sources/Network tab).
2. Private Repo ≠ Private Site While your GitHub repository may be private, GitHub Pages delivers web bundles across a public CDN. Private Pages require GitHub Enterprise.
3. Automated Secret Scanning Committing a live Google API key triggers GitHub & Google Secret Scanning, which automatically disables/revokes the key. Storing it in localStorage avoids all risk.
